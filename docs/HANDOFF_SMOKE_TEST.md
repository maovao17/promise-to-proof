# P2P-HANDOFF-001 — Manual handoff test (scope v1)

This documentation-only test follows the coordinator → builder → reviewer handoff. The coordinator records the approved scope and acceptance criteria, the builder commits this document, and the reviewer independently inspects that exact commit before reporting the outcome in the dedicated room.

The test passes when:

- The builder's commit changes only `docs/HANDOFF_SMOKE_TEST.md`, with no product code changes.
- The reviewer independently checks the exact commit against scope v1 and its acceptance criteria.
- The reviewer reports the outcome and supporting evidence in the room.

Release and deployment are out of scope.
